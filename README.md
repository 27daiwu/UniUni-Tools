# UniUni Tools 用户手册

UniUni Tools 用于在 Windows 本地编辑 Unitree 多机器人舞蹈工程、编排舞序、编辑队形并生成舞蹈包。核心编舞功能可离线使用，不连接机器人。

当前版本：**v1.2.0**。适用平台：**Windows x64**。

## 下载与启动

在 [Releases](https://github.com/27daiwu/UniUni-Tools/releases/latest) 下载 `UniUni-Tools-v1.2.0.exe`，双击运行，无需安装，也无需额外安装 Node.js 或 Python。

可在“帮助 → 关于 UniUni Tools”查看运行版本，在“帮助 → 检查更新”手动查询正式版本；软件不会自动下载或安装更新。

## 新建工程

1. 点击顶部“新建工程”，填写工程名称、舞台长度、舞台宽度和 BOT 数量；支持 3–13 台 BOT。
2. 创建后默认进入“候场位置”模式。可以直接使用默认候场队形，也可以拖动 BOT 或修改坐标、朝向后保存。
3. 在左侧工程动作中添加舞蹈，或从队形库添加队形，开始编排。

候场位置与正式节目队形分别编辑。尚未添加队形时，也可以进入“队形编辑”编辑预设队形，保存后加入当前舞序。

## 打开已有工程

点击“打开 / 导入工程”，选择 `.tar`、包含 TAR 的 `.zip`，或 `.unitool` 工程文件。打开后默认进入“节目预览”，请核对工程名称、舞序和 BOT 数量。

`.unitool` 用于保存可继续编辑的工程，不是机器人直接执行的 TAR 文件。导入的原始 TAR 及机器人映射会随工程保留。

## 使用主画布

“节目预览”“候场位置”“队形编辑”共用一个画布和缩放、平移视角；切换模式不会重新规划。

- 在画布空白处拖动即可平移；编辑模式下拖动 BOT 可调整其位置。
- 鼠标位于画布内时使用滚轮缩放，悬停查看世界坐标。
- 使用工具栏显示或隐藏栅格、轨迹，调整缩放或使用全屏画布。
- Shift 加拖动保留框选；坐标、朝向及栅格设置在画布下方的队形详细设置中调整。
- 舞台边界显示长宽，观众席文字用于辨认朝向。

当前舞序默认展开，最多显示四个完整条目，更多内容在列表内滚动。可手动收起舞序，给画布腾出空间；添加队形后列表自动滚到底部。

## 编辑队形

选择舞序中的队形后点击“编辑队形”，或切换到“队形编辑”模式。单击舞蹈或队形只选中，不自动跳转时间轴或开始编辑。

拖动 BOT，或在默认可见的坐标表中编辑 X、Y 和朝向。队形名称、坐标及舞台范围等修改先保存在编辑缓冲区，点击“保存编辑”后提交，保存后仍停留编辑模式。点击“放弃修改”恢复上次保存的内容。

有未保存修改时，先保存或放弃，再切换工程、队形或模式。

### 使用预设与队形DIY

在“队形预设”中选择预设，核对 BOT 数量、间距和舞台范围，确认应用后保存编辑。

在队形库点击“队形DIY”，可以拖动 BOT 或输入坐标，设置配对后使用镜像、中心对称，再命名并保存到自定义队形库。对称操作不会改变 BOT 编号和对应关系。自定义队形保存后可添加到当前舞序。

## 编排舞序和舞蹈

1. 在左侧“工程动作”点击加号添加舞蹈，或拖入当前舞序。
2. 拖动舞序条目调整顺序，也可使用条目上的顺序按钮。
3. 使用“插入队形”或队形库添加站位。
4. 根据需要修改编排时长和队形变换时间。编排时长不会修改原始舞蹈动作轨迹；不满足运动约束的时长会被拒绝。

支持同一队形连续执行多支舞蹈，也可以从默认或已编辑的候场位置直接开始舞蹈。

### 手动添加单支舞蹈

点击“手动添加舞蹈”，填写现有舞蹈对应的信息和时长，适用机型从 G1、H2、As2 中选择。请先确认目标机型具备该舞蹈；机型选择不会转换或生成动作资源，工程机型兼容校验仍会执行。

## 导入或替换地图

地图需先在 UniUni 中准备好。右侧地图区域点击“导入 / 替换地图”，选择一个包含地图资源与场景元数据的 `.tar` 包。

应用会检查 TAR 和必要的 PCD、PNG、BIN、场景元数据完整性，通过后直接替换地图，无需另外提交坐标关系文件。地图替换只更新地图附件与相关元数据，原有舞序、BOT、队形、轨迹和初始化点保持不变，不会自动转换编舞坐标。

替换地图可保存到 `.unitool`，也可随新建或已有工程导出 TAR。这里只消费已准备好的地图，不负责创建或校准地图。

## 规划与预览

后台规划检查 BOT 编号与映射、舞台范围、运动速度、加速度、转弯约束、全时间线连续碰撞以及预览与导出轨迹的一致性。机器人中心距要求严格大于 1.0 米。

需要规划的工程应先等待规划完成并处理检查问题，再播放或导出。候选路线未通过检查时保留原路线。规划需要延长演出时长时，会显示调整后的时长；符合约束的手动时长修改保留现有路径。

预览播放期间编辑控件锁定，暂停后继续编辑。

## 保存与导出

在顶部“保存为”选择：

- **工程文件（.unitool）**：用于继续编辑，建议完成一轮修改后保存备份。
- **群控文件（.tar）**：用于导入 UniUni；生成编排 TAR 时需具备有效动作资源，并通过既有规划及导出检查。

重新打开 `.unitool` 后，可复核 BOT 数量和编号、候场位置、队形坐标、舞序、时长及地图。未编辑的原始 TAR 可原样导出；重新编排或替换地图后使用对应导出结果。

## 常见问题

**为什么切换不了模式或工程？**

检查是否有未保存的队形或工程修改，按提示保存或放弃。

**为什么播放或 TAR 导出不可用？**

通常是规划尚未完成、存在未解决的碰撞或时间约束、动作时长无效，或缺少有效 TAR 模板和动作资源。请查看规划检查和顶部提示。

**为什么手动选择机型后仍不能加入舞蹈？**

当前工程的机型兼容检查仍会生效。请确认舞蹈资源与工程机型匹配。

**如何避免丢失修改？**

队形修改后先“保存编辑”，再保存 `.unitool`；重要调整前保留原始工程备份。
