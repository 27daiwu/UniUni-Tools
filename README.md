# UniUni Tools 用户手册

UniUni Tools 用于在 Windows 本地编辑 Unitree 多机器人舞蹈工程、编排舞序、编辑队形并生成舞蹈包。它不连接机器人，也不负责创建或校准地图。

## 使用前准备

地图相关工作请先在 UniUni 中完成：

1. 在 UniUni 新建或准备好带有正确地图、机器人数量和 BOT 映射的工程。
2. 在 UniUni 中确认地图坐标系、场地尺寸和机器人初始信息。
3. 将需要继续编排的舞蹈包或 TAR 工程保存到本地。

UniUni Tools 中的地图区域只用于查看工程携带的地图资源，或在已有工程上导入经过确认的地图资源。不要在这里猜测地图与舞台坐标的对应关系；坐标关系不明确时，地图不会叠加到栅格上。

## 新建工程

1. 启动 UniUni Tools，点击顶部的“新建工程”。
2. 在确认框中填写工程名称、舞台长度、舞台宽度和 BOT 数量。BOT 数量必须在 3 到 13 台之间。
3. 点击“创建工程”。创建完成后会直接进入“候场位置编辑”，候场位置不会自动加入节目单。
4. 在舞台栅格上拖动机器人，或打开“机器人位置”编辑坐标和朝向。使用“栅格吸附”可以统一坐标精度。
5. 编辑完成后点击“保存编辑”。如果只是试验位置，点击“放弃修改”恢复上次保存内容。
6. 点击“完成并开始编排”，进入主编排界面。之后可以随时点击顶部“编辑候场位置”返回候场位置编辑。

未保存队形编辑时切换队形会被阻止。先保存或放弃当前修改，再切换到其他队形。

## 打开已有舞蹈包

1. 点击“打开 / 导入工程”。
2. 选择 `.tar`、包含 TAR 的 `.zip`，或之前保存的 `.unitool` 工程文件。
3. 导入后先检查工程名称、舞序、BOT 数量和队形。源 TAR 的机器人映射和原始资源会被保留。
4. 如果工程需要地图，请回到 UniUni 完成地图处理；UniUni Tools 不会替代 UniUni 的地图创建流程。

`.unitool` 是 UniUni Tools 的本地编辑工程文件，用于保存队形、舞序、时长和规划草稿。它不是机器人直接执行的 TAR 文件。

## 编辑队形

### 编辑现有队形

1. 在主编排界面打开“队形库”，选择节目单中的队形并点击“编辑队形”。
2. 在栅格上拖动 BOT，或在“机器人位置”表格中修改 X、Y 和朝向。
3. 需要时设置栅格吸附、整体平移或舞台范围。
4. 点击“保存编辑”提交修改。点击“放弃修改”撤销本次未保存编辑。

队形名称、坐标、舞台范围和初始化状态都属于编辑缓冲区，只有点击“保存编辑”后才会写入当前工程。保存后重新打开 `.unitool`，再进入同一队形即可复核 BOT 坐标。

### 使用内置队形预设

“队形预设”是只读素材，不能直接覆盖。选择预设后先查看画布预览，确认机器人数量、间距和舞台范围，再点击“确认应用”。应用结果会进入当前队形的编辑缓冲区，仍需点击“保存编辑”才会提交。

### 创建自己的 DIY 队形

1. 打开“队形库”，点击“队形编辑 · DIY”。
2. 编辑器会按照当前工程 BOT 数量生成机器人，默认在舞台中央一字排开，编号与 BOT 对应。
3. 拖动机器人，或在坐标表中输入 X、Y、朝向；可使用栅格吸附。
4. 如需对称排列，先选择参与操作的机器人和配对对象，再使用“镜像”或“中心对称”。镜像以舞台中心轴为基准，中心对称以舞台中心为基准。
5. 奇数台 BOT 未配对时，未配对机器人默认放在中心点；可以继续手动拖动。偶数台 BOT 按配对对象排列。
6. 对称操作不会改变 BOT 编号和对应关系。
7. 输入队形名称，点击“保存到自定义队形库”。之后可在“队形库”中将它添加到节目单。

## 编排舞序和动作

1. 在左侧“工程动作”中选择动作，点击加号加入节目单。
2. 拖动节目单项目可以调整动作和队形的顺序。
3. 点击动作可以查看或修改“编排时长”。时长修改只影响编排时间，不修改 TAR 内原始动作轨迹。
4. 点击“插入队形”或从“队形库”拖入队形，可以在动作之间加入站位。
5. 队形变换时间在“队形变换设置”中修改。满足运动约束的修改会直接生效，并以消息气泡提醒，不会弹出确认窗口；过短或不满足约束的值会被拒绝。

## 规划和检查

规划会在后台计算候选路线。编辑器会检查：

- BOT 编号和对应关系是否保持一致；
- 舞台范围、运动速度、加速度和转弯约束；
- 全时间线上的连续碰撞风险；
- 机器人中心距是否严格大于 1.0 米；
- 预览轨迹与导出 TAR 轨迹是否一致。

只有规划完成且检查通过后，播放预览和正式 TAR 导出才会开放。候选路线未通过检查时会保留原路线，不会为了缩短时间降低安全间距。

建议先处理“规划检查”中的问题，再播放预览。播放时编辑控件会锁定；暂停后可以继续编辑。

## 保存、重新打开和导出

### 保存可继续编辑的工程

在顶部“保存为”中选择“工程文件（.unitool）”。建议在每次完成队形、舞序或规划修改后保存一个 `.unitool` 版本。

重新打开时选择该 `.unitool` 文件，检查 BOT 数量和编号、候场位置、已保存队形的 BOT 坐标、舞序和队形变换时间，以及规划检查状态。

### 导出舞蹈包

绑定真实 TAR 模板、完成动作和队形编排，并通过连续碰撞检查后，在“保存为”中选择“群控文件（.tar）”。导出前应在 UniUni 中确认地图和工程资源，再将导出的舞蹈包交给后续验收流程。

如果工程使用了替换地图或规划尚未通过检查，TAR 导出会被阻止。此时保存 `.unitool` 继续编辑，或回到 UniUni 处理地图和工程资源。

## 常见问题

**为什么修改队形后切换不了？**

当前队形有未保存修改。点击“保存编辑”或“放弃修改”后再切换。

**为什么改了队形变换时间却没有重新搜索路线？**

这是设计行为。满足约束的手动时长只调整运动速度，保留现有路径；不满足约束的修改会被拒绝。

**为什么播放或 TAR 导出按钮不可用？**

通常是规划仍在计算、存在未解决的碰撞或时间约束、缺少有效动作时长，或工程尚未绑定真实 TAR 模板。先查看“规划检查”和状态提示。

**地图在哪里创建？**

地图在 UniUni 中新建、校准和确认。UniUni Tools 只消费已经准备好的工程或经过核实的地图资源，不负责替代 UniUni 的地图制作流程。

**如何避免丢失修改？**

编辑队形后先点击“保存编辑”，再保存 `.unitool`。导出 TAR 前也建议先保存一个 `.unitool` 备份。
