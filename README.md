# UniUni Tools

**免费、简洁的 Unitree UniUni 多机器人舞蹈编排辅助工具**

UniUni Tools 是由 JazzZhou 独立开发的 Windows 桌面软件，旨在帮助用户更方便地编辑多机器人舞蹈节目、设计队形、规划运动轨迹及管理编舞工程。

本工具为第三方独立开发项目，并非宇树官方软件。

## 主要功能

- **多机器人编舞**：支持 3–13 台机器人进行舞蹈编排。
- **队形编辑**：提供内置队形预设，支持自定义队形、拖动编辑、镜像和中心对称。
- **自动轨迹规划**：自动规划机器人换队形路线，并进行运动约束与碰撞风险检查。
- **舞蹈节目单**：组合机器人队形、运动轨迹和动作，支持编排顺序及时间调整。
- **舞台编辑**：支持自定义舞台尺寸、机器人数量和候场位置。
- **模拟预览**：预览多机器人舞蹈过程，检查运动轨迹。
- **文件管理**：支持相关 TAR/ZIP 文件导入、`.unitool` 工程保存及 TAR 导出。
- **离线使用**：核心编舞功能无需互联网连接。
- **检查更新**：可手动查看 GitHub 发布的新版本。

## 使用方法

1. 运行 UniUni Tools。
2. 新建工程，设置舞台尺寸和机器人数量，或导入已有文件。
3. 编辑候场位置。
4. 从队形库选择队形，或创建自定义队形。
5. 在节目单中添加队形、轨迹及动作。
6. 自动规划并预览机器人运动。
7. 保存工程，或导出 TAR 文件。

## 注意事项

1. 本软件主要用于机器人舞蹈编排辅助及离线轨迹验证。
2. 自动避碰使用软件运动模型，不代表已经通过真机安全认证。
3. 实际机器人执行前，请核对机型、场地、机器人间距及运动约束，并在安全条件下充分测试。
4. TAR 文件与宇树原版 UniUni 软件的完整兼容性仍需进一步验证。
5. 建议在修改或导出任务前备份原始文件。
